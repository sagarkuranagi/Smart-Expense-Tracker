# Smart-Expense-Tracker
## Project Description
Smart Expense Tracker is a full-stack web application built using the MERN stack (MongoDB, Express.js, React.js, and Node.js) to help users manage their personal finances, track income and expenses, monitor budgets, and make smarter financial decisions.

The application provides an interactive dashboard with financial summaries, category-wise spending analytics, transaction management, and monthly budget tracking. It aims to go beyond traditional expense tracking by introducing intelligent spending anomaly detection, adaptive budget recommendations, and a savings simulator that helps users understand their spending patterns and plan their financial goals.

Users can record and categorize transactions, analyze spending trends through visual charts, receive alerts when spending exceeds defined limits, and explore potential savings by adjusting their budgets. The application follows a modular architecture with RESTful APIs, database operations, input validation, and a responsive React interface.

## Key Features

- **Income and Expense Management:** Create, view, update, and delete financial transactions.
- **Interactive Dashboard:** View total income, expenses, balance, and spending analytics.
- **Smart Spending Alerts:** Identify unusual spending patterns and highlight categories with increased expenses.
- **Adaptive Budget Planning:** Set monthly category budgets and receive spending-limit warnings.
- **Savings Simulator:** Explore how reducing expenses can improve monthly and annual savings.
- **Visual Analytics:** Analyze financial data using charts and category-wise breakdowns.
- **Responsive UI:** Access the dashboard across desktop, tablet, and mobile devices.

## Technology Stack

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **API:** RESTful APIs
- **Tools:** Git, GitHub, VS Code, Postman

## Project Objective

The objective is to develop a reliable, user-friendly financial management application that combines transaction tracking with practical spending insights. The project demonstrates full-stack development, API design, database integration, data visualization, and problem-solving using the MERN stack.
